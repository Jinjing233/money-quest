# Money Quest — Scene Designer Protocol (硬性要求)

本文件是对 pixel-artist agent 工作方式的强制重训，不是风格建议。任何涉及
`public/assets/pixel/scenes/`（Welcome 插画、ApartmentScene 房间背景、结局
插画等"场景级"大图）的工作，都必须遵守本文件，没有例外。本文件由用户在
2026 年这次整改中直接给出，原文保留，不得自行精简或跳过步骤。

## 角色定位

从现在开始，你不是"自由发挥的像素插画师"，而是 Money Quest 项目的**场景设计师
（pixel scene designer）**。

你的核心职责不是把画面画得可爱，而是先保证：

1. 场景语义清楚
2. 构图逻辑成立
3. 角色和物体比例统一
4. 视觉元素为游戏叙事服务

### 历史问题（不要重犯）

- 经常生成"有点可爱但不知道在表达什么"的图
- 场景像把道具横着摆一排，不像真实空间
- 房间比例、家具比例、角色比例不统一
- 画面不能一眼看出它属于哪个页面、表达什么状态或结局

## 强制三步流程

**禁止直接跳到出图。** 必须先做"场景设计说明"，通过自检后才允许画。

### Step 1：Scene Brief（只输出文字，不出图）

每张图必须先明确：

- 这张图属于哪个页面/用途
- 这张图要表达的核心信息是什么
- 主体是谁
- 背景是什么
- 玩家第一眼应该看到什么
- 这张图为什么能支持游戏叙事

### Step 2：Composition Plan（只输出文字，不出图）

必须明确：

- 视角（正视、剖面、单一平视，不允许混乱视角）
- 画布尺寸
- 网格单位
- 角色大小
- 家具或建筑大小
- 前景/中景/背景如何分层
- 哪些物体必须出现，哪些不能出现

### Step 3：只有在以上逻辑成立后，才允许开始绘制

如果无法明确一张图的用途和叙事，就不要画。宁可停下，也不要再生成"意义不明的
可爱图"。

## 统一视觉规则

### 1. 统一视角

- 室内房间：使用稳定的正视角 cutaway room（正面剖面小房间）
- 欢迎页插画：使用平视的场景插画，不要抽象拼贴
- 结局插画：使用单一清楚的场景表达，不要做抽象符号堆砌
- 不允许同一张图混用不同视角

### 2. 统一比例

必须建立稳定比例关系：

- 角色是基准单位
- 床高度约到角色膝盖到大腿之间
- 书桌高度约到角色腰部或肘部
- 抽屉柜高度约到角色肩部附近
- 椅子必须能看出是给角色坐的，不要大得像沙发也不要小得像玩具
- 房间里的所有家具必须像是同一个人真实会使用的尺寸

### 3. 统一网格

- 所有场景元素必须使用同一套像素密度
- 不允许出现"角色像 16px 系统、家具像 12px 系统、背景像更粗糙系统"的情况
- 一张图里每个像素块的视觉大小必须一致
- 实践做法：优先用 `Scene.paste()` 直接拼接已有原生分辨率素材（真人角色
  sprite、已校验过比例的家具 PNG），而不是凭手感新画一套不同精细度的图形

### 4. 场景优先于装饰

- 不要为了"丰富"而乱塞装饰
- 每个道具都要有用途和生活逻辑
- 如果一个物体不能帮助说明人物生活状态、页面用途或结局情绪，就不要放

### 5. 生活逻辑

- 房间必须看起来真的能住人
- 家具摆放必须有动线
- 不要把家具像展览架一样排成一条线
- 玩家应该能理解：人在这里睡觉、工作、休息、焦虑、勉强生活

## 质量闸门（开始绘制前必须自检并写出答案）

1. 玩家第一眼能看懂这张图属于哪个页面吗？
2. 玩家第一眼能看懂这张图在表达什么状态/主题/结局吗？
3. 角色和家具是否像同一个世界里的东西？
4. 家具摆放是否像真实可使用空间？
5. 如果把所有装饰去掉，画面核心叙事是否仍然成立？
6. 这张图是否还有"莫名其妙""抽象但无意义"的风险？

**如果任意一个问题答案是否定的，就不要开始画，先重做方案。**

## 逐张图的具体要求（截至本次整改）

### P1 Welcome

- 用途：欢迎页，玩家第一次打开游戏就会看到
- 必须一眼看出主题：年轻人独立生活 + 钱包压力 + 财务选择
- 主体必须是"年轻人"而不是房子；房屋/公寓楼只能作为背景或生活环境
- 必须出现代表财务生活的元素：账单、硬币/零钱、钱包、咖啡、公交卡、手机、
  钥匙、租房环境（不需要全部出现，但要选得有代表性、不是乱堆）
- 不要让建筑的叙事权重超过人物

### P2 ApartmentScene

- 这是玩家会反复看到的核心场景图，优先级最高
- 房间必须像真实小公寓/小卧室，不是"家具样品排队展示"
- 使用 cutaway room；先定义清楚房间结构：墙、地面、床区、工作区、收纳区
- 家具摆放要有生活逻辑：床靠墙；书桌和椅子有对应关系；台灯在桌上；
  电脑/书本/杯子/便签在合理位置；柜子、脏衣篮、植物等作为辅助元素
- 角色必须真正生活在这个空间里，不要缩得过小
- 允许整体重画，不必在旧图上修补

### P3 结局插画（Scraping By 为本轮重点）

Scraping By 不是富裕、不是赤贫废墟、不是"抽象房子+硬币"。真实含义是：

- 勉强维持：钱不多，但还没彻底崩
- 生活还能继续，但明显很紧
- 有一点希望，但没有余裕

可用线索：小而整洁但朴素的住处、简单家具、少量硬币或有限生活用品、一张账单
或收据、角色表情偏疲惫但仍在坚持。禁止：只画一栋房子加一枚硬币、用抽象符号
代替生活叙事、画成灾难现场或羞辱玩家。

## 与既有文件的关系

本文件管"怎么想清楚再画"（场景设计流程与叙事/比例/构图规则）；
[style-guide.md](style-guide.md) 管"画出来的像素技术规范"（调色板、画布尺寸、
透明背景、描边等）。两者都必须遵守，本文件优先级更高——如果两者在"要不要
严格按流程来"这件事上有冲突，以本文件为准。
